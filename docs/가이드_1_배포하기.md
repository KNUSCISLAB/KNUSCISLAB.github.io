# 가이드 1. 새 홈페이지를 GitHub에 올리기

이 문서를 처음부터 순서대로 따라 하시면 됩니다. 한 번만 하면 되는 작업이고, 30분 정도 걸립니다.
모든 작업은 웹 브라우저(크롬 권장)에서 할 수 있어요. 프로그램 설치는 필요 없습니다.

완성되면 홈페이지 주소는 **https://knuscislab.github.io** 가 됩니다.

---

## 준비물

- GitHub 계정 `KNUSCISLAB` 로그인
- 받은 압축 파일을 풀어 둔 폴더. 안에 이런 폴더가 있습니다.
  - `업로드_1_사이트파일` : 홈페이지 본체
  - `업로드_2_논문파일` : 논문 데이터 (파일 수가 많아서 따로 올립니다)
  - `설정파일_복사용` : 마지막에 복사해서 붙여 넣을 설정 2개

> 왜 두 번에 나눠 올리나요? GitHub 웹에서는 한 번에 100개까지만 올릴 수 있어서, 논문 파일(66개)을 따로 올립니다.

---

## 0단계. 이미 `KNUSCISLAB.github.io` 저장소가 있다면

예전에 만든 저장소가 있으면 이름이 겹칩니다. 지우지 말고 이름만 바꿔서 백업해 두세요.

1. https://github.com/KNUSCISLAB/KNUSCISLAB.github.io 에 들어갑니다.
2. 위쪽 **Settings** 를 누릅니다.
3. 맨 위 **Repository name** 칸을 `old-homepage` 로 바꾸고 **Rename** 을 누릅니다.

없다면 이 단계는 건너뛰세요.

---

## 1단계. 새 저장소 만들기

1. https://github.com/new 에 들어갑니다.
2. **Repository name** 에 정확히 `KNUSCISLAB.github.io` 라고 적습니다.
3. **Public** 을 선택합니다.
4. 아래 "Add a README file" 등은 **체크하지 않습니다**.
5. **Create repository** 를 누릅니다.

---

## 2단계. 홈페이지 파일 올리기 (1차)

1. 방금 만든 저장소 화면에서 **uploading an existing file** 이라는 파란 글씨를 누릅니다.
   (안 보이면 **Add file → Upload files**)
2. 컴퓨터에서 `업로드_1_사이트파일` 폴더를 엽니다.
3. 폴더 **안에 있는 것 전부**를 선택해서(Windows: Ctrl+A, Mac: Cmd+A) 브라우저 화면으로 끌어다 놓습니다.
   폴더 자체가 아니라 **안의 내용물**을 끌어야 합니다.
4. 업로드 목록이 다 뜰 때까지 기다린 뒤, 아래 **Commit changes** 를 누릅니다.

확인: 저장소에 `index.html`, `assets`, `data`, `scripts` 등이 보이면 성공입니다.

---

## 3단계. 논문 파일 올리기 (2차)

1. 저장소 화면에서 **data** 폴더를 눌러 들어갑니다.
2. **Add file → Upload files** 를 누릅니다.
3. 컴퓨터에서 `업로드_2_논문파일` 폴더를 열고, 그 안의 **publications 폴더를 통째로** 끌어다 놓습니다.
4. **Commit changes** 를 누릅니다.

확인: `data/publications` 폴더 안에 `2025-...json` 같은 파일이 66개 보이면 성공입니다.

---

## 4단계. GitHub Pages 켜기

1. 저장소 위쪽 **Settings** 를 누릅니다.
2. 왼쪽 메뉴에서 **Pages** 를 누릅니다.
3. **Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
   (Deploy from a branch 가 아닙니다. 꼭 GitHub Actions 로 해 주세요.)

저장 버튼은 따로 없습니다. 선택만 하면 됩니다.

---

## 5단계. 설정 파일 2개 만들기

컴퓨터의 `설정파일_복사용` 폴더에 있는 파일 두 개의 내용을 복사해서 붙여 넣는 단계입니다.
(이름이 점(.)으로 시작하는 파일은 컴퓨터에서 숨김 파일이라 끌어다 놓기로는 잘 안 올라가서, 이렇게 만듭니다.)

### 5-1. 관리 화면 설정 `.pages.yml`

1. 저장소 첫 화면(맨 위 `KNUSCISLAB.github.io` 글자를 누르면 돌아옵니다)에서 **Add file → Create new file** 을 누릅니다.
2. 파일 이름 칸에 `.pages.yml` 이라고 적습니다. (맨 앞 점 포함)
3. 컴퓨터에서 `설정파일_복사용/pages.yml` 을 메모장(또는 텍스트 편집기)으로 열어 **전부 복사**하고, 큰 입력칸에 붙여 넣습니다.
4. **Commit changes...** → 다시 **Commit changes** 를 누릅니다.

### 5-2. 자동 배포 설정 `deploy.yml`

1. 다시 **Add file → Create new file** 을 누릅니다.
2. 파일 이름 칸에 `.github/workflows/deploy.yml` 이라고 적습니다.
   `/` 를 입력하면 폴더가 자동으로 만들어지니 그대로 이어서 적으면 됩니다.
3. `설정파일_복사용/deploy.yml` 내용을 전부 복사해 붙여 넣습니다.
4. **Commit changes** 를 누릅니다.

이 파일을 저장하는 순간 홈페이지 배포가 **자동으로 시작**됩니다.

---

## 6단계. 배포 확인

1. 저장소 위쪽 **Actions** 를 누릅니다.
2. "Deploy website" 가 노란 원(진행 중)에서 **초록 체크**로 바뀔 때까지 1~2분 기다립니다.
3. https://knuscislab.github.io 에 접속해 봅니다. 🎉

처음에는 주소가 열리기까지 몇 분 더 걸릴 수 있어요. 10분 뒤에도 안 되면 아래 "문제가 생겼을 때"를 보세요.

---

## 7단계. 관리 화면 연결 (Pages CMS)

이제 앞으로는 코드를 보지 않고 관리 화면에서 내용을 고칩니다.

1. https://app.pagescms.org 에 들어갑니다.
2. **Sign in with GitHub** 로 로그인합니다.
3. GitHub App 설치 화면이 나오면 **Only select repositories** 를 고르고 `KNUSCISLAB.github.io` 하나만 선택한 뒤 **Install** 을 누릅니다.
4. 저장소를 열면 왼쪽에 **뉴스, 논문, 구성원, 교수 소개…** 메뉴가 보입니다.

여기까지 되면 설치 끝입니다. 사용법은 **가이드 2. 관리하기** 에 있습니다.

## 문제가 생겼을 때

**Actions 에 빨간 X 가 떴어요**
- 빨간 X 를 누르고 **build** 를 누르면 무엇이 문제인지 적혀 있습니다.
  예: `✗ data/news/2026-04-...json is not valid JSON` 처럼 파일 이름이 나옵니다.
- 4단계에서 Source 를 **GitHub Actions** 로 바꾸지 않았을 때도 실패합니다. 바꾼 뒤, 실패한 항목을 눌러 오른쪽 위 **Re-run all jobs** 를 누르세요.

**주소에 들어가면 404 가 떠요**
- 저장소 이름이 정확히 `KNUSCISLAB.github.io` 인지 확인하세요.
- Actions 가 초록 체크인지 확인하고, 5분 정도 기다린 뒤 새로고침하세요.

**내용이 비어 보이고 "일부 내용을 불러오지 못했습니다" 라고 나와요**
- 3단계(논문 파일)가 빠지지 않았는지 확인하세요.

**Pages CMS 에 메뉴가 안 보이고 ".pages.yml 을 만들라" 고 나와요**
- 5-1 단계의 파일 이름이 정확히 `.pages.yml` 인지(앞에 점, 끝이 yml) 확인하세요.
