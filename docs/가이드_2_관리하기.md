# 가이드 2. 홈페이지 내용 관리하기

새 홈페이지는 **관리 화면(Pages CMS)** 에서 입력칸만 채우면 됩니다.
저장하면 1~2분 뒤 홈페이지에 자동으로 반영돼요. 코드는 볼 필요가 없습니다.

관리 화면 주소: **https://app.pagescms.org** (무료, 오픈소스)
로그인 계정: **KNUSCISLAB** GitHub 계정 하나로 관리합니다.

---

## 기본 흐름 (모든 작업이 같아요)

1. app.pagescms.org 접속 → GitHub로 로그인(KNUSCISLAB) → `KNUSCISLAB.github.io` 선택
2. 왼쪽 메뉴에서 고칠 항목 선택 (뉴스, 논문, 구성원 …)
3. 새로 만들 때는 오른쪽 위 **추가 버튼**(Add entry), 고칠 때는 목록에서 항목 클릭
4. 입력칸 채우기
5. 오른쪽 위 **저장 버튼**(Save)
6. 1~2분 기다린 뒤 홈페이지 새로고침

> 홈페이지는 **영어가 기본**이고, 오른쪽 위 "한국어" 버튼으로 한글을 봅니다.
> 한글 칸을 비워 두면 한글 화면에서도 영문 내용이 대신 나옵니다. 급할 때는 영문만 채우셔도 괜찮아요.

---

## 메뉴 한눈에 보기

| 관리 화면 메뉴 | 홈페이지에서 나오는 곳 |
|---|---|
| 뉴스 (News) | News(소식) 페이지, 홈 화면 최신 소식 3개 |
| 사진 (Photos) | Photos(사진) 페이지 행사별 앨범 |
| 논문 (Publications) | Publications(논문·특허) 페이지, Research 페이지 "관련 논문", 홈 화면 대표 논문 |
| 특허·프로그램 (Patents) | Patents(특허) 페이지 |
| 연구과제 (Projects) | Projects(연구과제) 페이지 |
| 참여 사업·센터 (Programs) | Projects 페이지 "Affiliated centers" |
| 국제 공동연구 기관 (Collaborations) | Projects 페이지 "International collaboration" |
| 구성원 (People) | Researchers(구성원) 페이지 |
| 교수 소개 (Professor) | Professor(지도교수) 페이지: 사진, 약력, 수상, 활동 |
| 초청 강연 (Talks), 언론 보도 (Press) | Professor 페이지 아래쪽 |
| 연구 주제 (Research) | Research 페이지 주제 카드, 홈 화면 연구 소개 |
| 홈페이지 기본 설정 (Settings) | 로고, 홈 화면 제목·소개, 학생 모집 안내, 주소·연락처 |

**관리 화면에서 못 고치는 것**: 메뉴 이름, 각 페이지 제목 아래 안내 문구, 섹션 제목·버튼 글자, 홈 화면 그림, 디자인.
이런 부분은 코드 파일(`assets/js/i18n.js` 등)에 있어서 Claude에게 요청하거나 GitHub에서 직접 고칩니다.

## 자주 하는 일

### 1. 새 논문이 게재됐을 때

**논문 (Publications) → 추가 버튼**

| 칸 | 적는 법 | 예시 |
|---|---|---|
| 구분 | 심사 중·투고 / SCIE / ESCI(SCOPUS) / KCI / 기타 학술지 / 국제학술대회 / 국내학술대회 | SCIE 국제학술지 |
| 연도 | 숫자 | 2026 |
| 게재 연-월 | 선택 | 2026-04 |
| 정렬 순서 | **보통 비워 두세요** (아래 설명) | |
| 논문 제목 (영문) | 논문 그대로 | PAR-LLM: Peak-Aware Residual LLM … |
| 논문 제목 (한글) | 한글 논문일 때만 | |
| 저자 | 논문에 나온 순서대로, **교신저자에 \*** | Hwang, J., Suh, D.\* |
| 서동준 교수 역할 | 교신저자 / 제1저자·교신저자 / 제1저자 / 공동저자 | 교신저자 |
| 학술지·학술대회 이름 | | IEEE Access |
| 권(호), 페이지 | 선택 | 14, 52360–52370 |
| DOI | `https://doi.org/` 는 빼고 | 10.1109/ACCESS.2026.3679962 |
| 게재 정보 | 선택 | 2026.01 (online 2025.09) |
| 상태 | 선택 | In press, Accepted |
| JCR 연도 | | 2025 |
| Impact Factor | 숫자 | 4.2 |
| JCR 분위 | Q1~Q4 | Q2 |
| JCR 상위 % | 숫자만 | 33.5 |
| JCR 분야, 분야 내 순위 | | Engineering, Electrical & Electronic / 124/369 |
| 메모 | 학술대회일 때 | Oral, Scopus |
| 연구 분야 | Energy AI / Industrial AI / 기후변화 정책 / 위험 관리 / 기타 | Energy AI |

KCI·국내학술대회·기타 학술지는 JCR 칸을 비워 두면 됩니다.

이렇게만 저장하면 다음이 **자동으로** 바뀝니다.

- 논문 번호 [J1], [E1], [K1], [C1], [D1] (분류별로 **최신 논문이 1번**)
- 홈 화면 "Recent publications"의 태그와 JCR 정보
- 연도별 정리와 SCIE·ESCI·KCI·학술대회 태그, 분류 버튼 필터, 검색, 페이지 위쪽 숫자 (SCIE 논문 N편 등)
- Research 페이지의 "관련 논문"

**정렬 순서 칸**: 같은 해 안에서 순서를 정하는 숫자입니다(작을수록 위).
비워 두면 새 논문이 **그 해의 맨 위**에 놓이고 번호가 자동으로 다시 매겨집니다.
기존 논문에는 CV 번호대로 숫자가 들어 있으니 그대로 두세요. 순서를 직접 맞추고 싶을 때만 씁니다.

**심사 중 논문이 게재 확정되면**: 그 논문을 열어 **구분**을 "SCIE 국제학술지" 등으로 바꾸고, DOI·권호·IF·JCR 칸을 채운 뒤 저장합니다.

**IF·JCR을 매년 갱신할 때**: 논문을 하나씩 열어 JCR 연도, Impact Factor, 분위, 상위 %를 고칩니다.
여러 편을 한꺼번에 바꾸려면 정리한 표를 Claude에게 주고 일괄 수정을 요청하는 편이 빠릅니다.

**홈 화면 대표 논문**: "홈 화면 대표 논문으로 표시"를 켠 논문 중 최신 3편이 첫 화면에 나옵니다.
"대표 그림"에 논문의 핵심 그림(모델 구조도 등)을 올리면 훨씬 보기 좋아요.

### 2. 특허·프로그램 등록

**특허·프로그램 (Patents) → 추가 버튼**

- **구분**: 국내 등록특허 / 미국 등록특허 / 출원 중 (국내·미국·PCT) / 프로그램 등록
- **국가**: KR / US / PCT (출원 중일 때 번호 앞에 표시)
- **명칭**: 영문과 한글
- **등록번호, 등록일**: 등록된 것만 (예: 10-2954774, 2026-04-15)
- **출원번호, 출원일, 공개번호**
- **진행 상태**: 출원 중일 때 (예: Under examination / 심사 중)
- **발명자**: 영문과 한글
- **정렬 순서**: 보통 비워 두세요. 비우면 그 구분의 맨 위(최신)에 놓입니다.

**출원 중이던 특허가 등록되면**: 그 항목을 열어 구분을 "국내 등록특허"로 바꾸고 등록번호·등록일을 채웁니다.

### 3. 뉴스 올리기

**뉴스 (News) → 추가 버튼**

- **날짜**: 연-월 (예: 2026-10)
- **종류**: 논문 / 수상·특허 / 발표·강연 / 과제·협력 / 모집 / 연구실 소식
- **제목, 내용**: 영문과 한글 (한글은 선택)
- **사진, 링크**: 선택
- **홈 화면 맨 앞에 고정**: 중요한 소식이면 켜기

학생 수상은 "수상·특허" 종류로 올리면 News 페이지의 수상 모아보기에 함께 나옵니다.
홈 화면에는 최신 뉴스 3개가 자동으로 나옵니다.

### 4. 연구과제

**연구과제 (Projects) → 추가 버튼**

- **구분**: 연구책임자(PI) / 공동연구원·참여연구원
- **시작, 종료**: 예) 2026-03, 2027-08. 종료일이 지나지 않았으면 "Ongoing" 표시가 자동으로 붙습니다.
- **역할**: 예) PI (Director) / 연구책임자 (사업단장)
- **과제명, 지원 기관·사업, 연구비**: 영문과 한글

### 5. 교수 소개, 수상, 활동

**교수 소개 (Professor)**

- 직위, 소속 학과, 연락처, 홈페이지 주소(여러 개), 사무실(여러 줄 가능), 사진, CV
- **수상**: 목록에서 항목 추가 → 날짜(예: 2027-03), 수상(영문), 수상(한글)
- **학회·위원 활동**: 영문 목록과 한글 목록이 따로 있습니다. 둘 다 고쳐 주세요.
- **초청 강연**, **언론 보도**는 각각 별도 메뉴(Talks, Press)입니다.

### 6. 국제 공동연구 기관

**국제 공동연구 기관 (Collaborations)**: 목록에 항목 추가 → 기관명, 국가(영문·한글), 비고(선택).
같은 국가끼리 자동으로 묶이고, "N개국 N개 기관" 숫자도 자동으로 바뀝니다.

### 7. 새 학생이 들어왔을 때

**구성원 (People) → 추가 버튼**

- **이름 (영문)**, **이름 (한글)**
- **구분**: 박사후연구원 / 연구원 / 박사과정 / 석사과정 / 학부 인턴 / 졸업생
- **사진**: 세로 사진도 괜찮습니다. 얼굴이 가운데 위쪽에 오게 잘립니다. 없으면 이니셜이 표시됩니다.
- **연구 관심사**, **이메일**
- **표시 순서**: 숫자가 작을수록 앞에 나옵니다.

### 8. 학생이 졸업하거나 연구실을 나갔을 때

- **졸업**: 그 학생을 열어 **구분**을 "졸업생"으로 바꾸고, **비고**에 `MS 2026` 처럼 적은 뒤 저장합니다.
- **졸업 없이 나간 경우**: 목록에서 그 학생을 열어 삭제합니다.

### 9. 사진·로고 바꾸기

- **연구실 로고**: 홈페이지 기본 설정 (Settings) → 연구실 로고. 가로로 긴 로고라면 높이 150px 정도의 PNG(투명 배경)가 좋습니다.
- **교수님 사진, CV**: 교수 소개 (Professor) → 사진 / CV 파일
- 관리 화면에서 올린 파일은 저장소의 `assets/uploads` 폴더에 보관됩니다.

### 10. 행사 사진 올리기

**사진 (Photos) → 추가 버튼**

- **날짜**: 예) 2025-08 (월을 모르면 2025)
- **앨범 제목**: 영문과 한글 (예: IBPSA Building Simulation 2025, Brisbane / IBPSA BS2025 국제학술대회, 호주 브리즈번)
- **사진**: 항목 추가 → 사진 올리기, 설명(선택). 설명을 비우면 앨범 제목이 쓰입니다.

Photos 페이지에 연도별로 앨범이 나오고, 사진을 누르면 크게 볼 수 있습니다.
휴대폰 원본 사진은 크기가 크니, 가능하면 긴 변 1,500px 정도로 줄여서 올려 주세요.

### 11. 학생 모집 안내 켜고 끄기

홈페이지 기본 설정 (Settings) → **학생 모집 중 표시** 를 켜거나 끕니다. 안내 문구도 여기서 고칩니다.

## 실수했을 때 되돌리기

모든 저장 기록이 남아 있어서 언제든 되돌릴 수 있어요.

- **항목 하나를 지운 경우**: GitHub 저장소 → 해당 폴더(예: `data/news`) → 오른쪽 위 **History** → 지우기 전 기록을 열어 내용을 복사해서 관리 화면에서 다시 만듭니다.
- **홈페이지가 깨진 경우**: GitHub 저장소 → **Actions** 에서 빨간 X 항목을 누르면, 어떤 파일이 문제인지 적혀 있습니다. 관리 화면에서 그 항목을 열어 고치면 됩니다.
- 잘 모르겠으면, 빨간 X 화면을 캡처해서 Claude에게 보여 주시면 같이 찾아 드릴게요.

## 알아 두면 좋은 것

- **반영 시간**: 저장 후 1~2분. 바로 안 보이면 브라우저 새로고침(Ctrl+Shift+R / Cmd+Shift+R).
- **언어**: 처음에는 누구에게나 영어로 보이고, 오른쪽 위 "한국어 / English" 버튼으로 바뀝니다. 한 번 고른 언어는 그 브라우저에서 기억됩니다.
- **다크 모드**: 방문자의 휴대폰·컴퓨터 설정을 따라가고, 오른쪽 위 동그라미 버튼으로 바꿀 수 있습니다.
- **논문 인용 복사**: 논문 페이지의 "Copy citation" 버튼으로 방문자가 인용 문구를 바로 복사할 수 있어요.
- **Pages CMS가 멈춘다면**: 홈페이지는 그대로 잘 나옵니다. 편집만 GitHub 웹사이트에서 `data` 폴더 파일을 직접 고치거나 Claude에게 요청하면 됩니다.
- **작업 폴더 주의**: 컴퓨터에서 저장소를 직접 다룰 때는 Dropbox·iCloud 동기화 폴더가 아닌 곳(예: `~/Developer/site-repo`)을 쓰세요. 동기화가 파일을 망가뜨릴 수 있습니다.
