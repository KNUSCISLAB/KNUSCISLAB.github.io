# 가이드 2. 홈페이지 내용 관리하기

새 홈페이지는 **관리 화면(Pages CMS)** 에서 입력칸만 채우면 됩니다.
저장하면 1~2분 뒤 홈페이지에 자동으로 반영돼요. 코드는 볼 필요가 없습니다.

관리 화면 주소: **https://app.pagescms.org**

---

## 기본 흐름 (모든 작업이 같아요)

1. app.pagescms.org 접속 → GitHub로 로그인 → `KNUSCISLAB.github.io` 선택
2. 왼쪽 메뉴에서 고칠 항목 선택 (뉴스, 논문, 구성원 …)
3. 새로 만들 때는 오른쪽 위 **추가 버튼**(Add entry), 고칠 때는 목록에서 항목 클릭
4. 입력칸 채우기
5. 오른쪽 위 **저장 버튼**(Save)
6. 1~2분 기다린 뒤 홈페이지 새로고침

> 한글 칸을 비워 두면 한글 페이지에서도 영문 내용이 대신 나옵니다. 급할 때는 영문만 채우셔도 괜찮아요.

## 자주 하는 일

### 1. 새 논문이 게재됐을 때

**논문 (Publications) → 추가 버튼**

| 칸 | 적는 법 | 예시 |
|---|---|---|
| 구분 | 국제 저널 / 심사 중 / 국제 학회 / 국내 | 국제 저널 |
| 연도 | 숫자 | 2026 |
| 논문 제목 | 논문 그대로 | Data-driven approach for … |
| 저자 | 논문에 나온 순서대로, 별표 없이 | Jeun, W., Hwang, J., Suh, D., Otto, M.-O. |
| 서동준 교수 교신저자 | 켜기 | 켜면 자동으로 **Suh, D.\*** 로 표시 |
| 저널·학회 이름 | | Energy & Buildings |
| 권·호·페이지 | 선택 | Vol. 345, 115944 |
| 지표 | 선택 | IF 6.6, JCR top 5.1% |
| DOI | `https://doi.org/` 는 빼고 | 10.1016/j.enbuild.2025.115944 |
| 연구 분야 | Energy AI / Industrial AI / 기후변화 정책 / 위험 관리 / 기타 | Energy AI |

이렇게만 저장하면 다음이 **자동으로** 바뀝니다.

- 논문 페이지 목록, 연도별 정리, 검색
- "국제 저널 논문 N편" 같은 숫자
- 연구 분야 페이지의 "관련 논문"

**JCR 상위 % 적는 법**: 가장 좋은 분야(category)를 기준으로, `100 − JIF Percentile` 로 계산합니다.
예: Percentile 95.0 → `JCR top 5.0%`

**심사 중 논문이 게재 확정되면**: 그 논문을 열어 **구분**을 "국제 저널"로 바꾸고, DOI와 권·호를 채운 뒤 저장하면 됩니다.

**홈 화면 대표 논문**: "홈 화면 대표 논문으로 표시"를 켠 논문 중 최신 3편이 첫 화면에 나옵니다.
"대표 그림"에 논문의 핵심 그림(모델 구조도 등)을 올리면 훨씬 보기 좋아요.

### 2. 뉴스 올리기

**뉴스 (News) → 추가 버튼**

- **날짜**: 연-월 (예: 2026-10)
- **종류**: 논문 / 수상·특허 / 발표·강연 / 과제·협력 / 모집 / 연구실 소식
- **제목, 내용**: 영문과 한글 (한글은 선택)
- **사진, 링크**: 선택
- **홈 화면 맨 앞에 고정**: 중요한 소식이면 켜기

홈 화면에는 최신 뉴스 3개가 자동으로 나옵니다.

### 3. 새 학생이 들어왔을 때

**구성원 (People) → 추가 버튼**

- **이름 (영문)**, **이름 (한글)**
- **구분**: 박사후연구원 / 연구원 / 박사과정 / 석사과정 / 학부 인턴 / 졸업생
- **사진**: 정사각형 사진 권장. 없으면 이니셜이 동그라미로 표시됩니다.
- **연구 관심사**, **이메일**
- **표시 순서**: 숫자가 작을수록 앞에 나옵니다.

### 4. 학생이 졸업했을 때

그 학생을 열어서 **구분**을 "졸업생"으로 바꾸고, **비고**에 `MS 2026` 처럼 적은 뒤 저장합니다.
(비고에 현재 소속을 함께 적어도 좋아요. 예: `PhD 2026, now at KEPCO`)

### 5. 사진·로고 바꾸기

- **연구실 로고**: 홈페이지 기본 설정 (Settings) → 연구실 로고 → 이미지 올리기
  (지금은 임시 표시가 들어가 있어요. 구글 사이트에 있던 로고 파일을 올려 주세요.)
- **교수님 사진, CV**: 교수 소개 (Professor) → 사진 / CV 파일
- 올린 파일은 저장소의 `assets/uploads` 폴더에 보관됩니다.

### 6. 학생 모집 안내 켜고 끄기

홈페이지 기본 설정 (Settings) → **학생 모집 중 표시** 를 켜거나 끕니다. 안내 문구도 여기서 고칩니다.

### 7. 연구 주제·과제·참여 사업

- **연구 주제 (Research)**: 분야를 "Energy AI (메인)", "Industrial AI (메인)", "기후변화 정책 (기타 연구)", "위험 관리 (기타 연구)" 중에서 고릅니다.
- **연구 과제 (Projects)**: 종료일이 지나면 자동으로 "완료"로 옮겨집니다. 종료일을 비우면 "진행 중"입니다.
- **참여 사업·센터 (Programs)**: 종료일을 비우면 "현재"로 표시됩니다.

## 학생에게 관리를 맡기려면

두 가지 방법이 있어요.

1. **GitHub 계정이 있는 학생**: GitHub 저장소 → Settings → **Collaborators** → Add people 로 학생을 추가하면, 학생도 Pages CMS에 로그인해서 편집할 수 있습니다.
2. **GitHub 계정이 없는 학생**: Pages CMS 저장소 화면의 **Collaborators(협업자)** 메뉴에서 학생 이메일로 초대할 수 있습니다. 학생은 이메일 링크로 들어와 내용만 편집할 수 있고, 설정은 바꿀 수 없어요.

누가 언제 무엇을 바꿨는지는 GitHub에 모두 기록되니 안심하셔도 됩니다.

추천 역할 분담 예시: 논문은 박사후연구원, 뉴스는 박사과정 학생 1명, 구성원 정보는 각자 본인.

## 실수했을 때 되돌리기

모든 저장 기록이 남아 있어서 언제든 되돌릴 수 있어요.

- **항목 하나를 지운 경우**: GitHub 저장소 → 해당 폴더(예: `data/news`) → 오른쪽 위 **History** → 지우기 전 기록을 열어 내용을 복사해서 관리 화면에서 다시 만듭니다.
- **홈페이지가 깨진 경우**: GitHub 저장소 → **Actions** 에서 빨간 X 항목을 누르면, 어떤 파일이 문제인지 적혀 있습니다. 관리 화면에서 그 항목을 열어 고치면 됩니다.
- 잘 모르겠으면, 빨간 X 화면을 캡처해서 Claude에게 보여 주시면 같이 찾아 드릴게요.

## 알아 두면 좋은 것

- **반영 시간**: 저장 후 1~2분. 바로 안 보이면 브라우저 새로고침(Ctrl+Shift+R / Cmd+Shift+R).
- **언어**: 오른쪽 위 "한국어 / English" 버튼으로 바뀝니다. 한국어 브라우저로 처음 들어온 방문자는 자동으로 한국어가 보여요.
- **다크 모드**: 방문자의 휴대폰·컴퓨터 설정을 따라가고, 오른쪽 위 동그라미 버튼으로 바꿀 수 있습니다.
- **논문 인용 복사**: 논문 페이지의 "Copy citation" 버튼으로 방문자가 인용 문구를 바로 복사할 수 있어요.
- **색상 바꾸기(선택)**: `assets/css/style.css` 맨 위의 `--accent` 값을 바꾸면 사이트 강조색이 한 번에 바뀝니다. 로고 색에 맞추고 싶을 때 쓰세요.
