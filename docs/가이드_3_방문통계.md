# 가이드 3: 방문 통계 (Site statistics)

홈페이지 방문자를 기관, 국가와 도시, 페이지, 체류 시간, 유입 경로별로 보여주는 자체 통계 시스템입니다.

- **대시보드**: https://knuscislab.github.io/stats.html (비밀번호 = `ANALYTICS_KEY`)
- **데모 화면**: https://knuscislab.github.io/stats.html?demo
- **비용**: Cloudflare 무료 플랜 안에서 0원. 한도를 넘어도 자동 과금되지 않습니다.

## 구성

| 파일 | 역할 |
|---|---|
| `assets/js/track.js` | 각 페이지에서 방문 정보를 수집 서버로 보냄 (쿠키 없음) |
| `analytics/worker.js` | Cloudflare Worker. 방문 기록 저장(`/collect`), 통계 계산(`/stats`) |
| `analytics/schema.sql` | Cloudflare D1 데이터베이스 표 구조 |
| `stats.html` | 대시보드 화면 |
| `.github/workflows/analytics.yml` | `analytics/` 폴더가 바뀌면 Cloudflare에 자동 배포 |

## 처음 한 번만: 연결하기

Cloudflare 계정은 연구실 계정(scislabknu@gmail.com)입니다.

1. **workers.dev 주소 정하기**: Cloudflare 대시보드에서 **Workers & Pages**를 한 번 엽니다. 하위 도메인을 정하라고 나오면 `scislab`처럼 정합니다.
2. **Account ID 복사**: 대시보드 첫 화면 오른쪽(또는 Workers & Pages 화면 오른쪽)에 있는 **Account ID**를 복사합니다.
3. **API 토큰 만들기**:
   1. 오른쪽 위 사람 아이콘 → **My Profile** → **API Tokens** → **Create Token**
   2. **Edit Cloudflare Workers** 템플릿 → **Use template**
   3. Permissions에 **+ Add more** → `Account` · `D1` · `Edit` 추가
   4. Account Resources: 연구실 계정 선택. Zone Resources: `All zones`
   5. **Continue to summary** → **Create Token** → 토큰 복사 (한 번만 보입니다)
4. **GitHub에 비밀값 등록**: 터미널에서 아래를 한 줄씩 실행하고, 물어보면 붙여넣습니다.

   ```bash
   cd ~/Developer/site-repo
   ```
   ```bash
   gh secret set CLOUDFLARE_API_TOKEN
   ```
   ```bash
   gh secret set CLOUDFLARE_ACCOUNT_ID
   ```
   ```bash
   gh secret set ANALYTICS_KEY
   ```
   `ANALYTICS_KEY`는 대시보드 비밀번호입니다. 직접 정해서 입력하세요(긴 문장 추천).
   `ANALYTICS_SALT`(방문자 익명화용 난수)는 이미 등록되어 있습니다.
5. **배포**: GitHub → Actions → **Deploy analytics server** → **Run workflow**. 끝나면 요약에 Worker 주소가 나옵니다.
6. 그 주소의 하위 도메인을 `assets/js/track.js`와 `stats.html`의 `WORKERS_SUBDOMAIN` 자리에 넣고 push하면 수집이 시작됩니다.

## 사용 팁

- 목록의 아무 줄이나 누르면 대시보드 전체가 그 기관, 국가, 페이지 등으로 필터됩니다.
- **Visitor organizations**의 **Institutions**는 대학, 연구소, 기업만 보여줍니다. **All networks**는 KT, SK브로드밴드 같은 통신사와 클라우드(대개 봇)까지 보여줍니다.
- 집이나 휴대폰에서 접속한 사람은 기관이 아니라 통신사로 잡힙니다. 기관 판별은 학교나 회사 네트워크에서 접속한 경우에만 됩니다.
- 대시보드를 연 기기는 자동으로 집계에서 빠집니다. 다른 기기를 빼려면 아무 페이지 주소 뒤에 `?notrack`을 붙여 한 번 열면 됩니다(`?track`으로 되돌림).
- IP 주소는 저장하지 않습니다. 방문자 구분값은 매일 바뀌는 해시라서 같은 사람을 며칠에 걸쳐 추적할 수 없습니다.
